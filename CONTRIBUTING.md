# Contributing

This project accepts contributions only from contributors explicitly
approved by the project maintainers.

## Authorized contributors

The following GitHub users are currently authorized to contribute:

- @xsedlak272

Other users should not submit pull requests unless invited by a maintainer.
Unsolicited pull requests will be closed without review.

## Contribution workflow

Authorized contributors should:

1. Discuss significant changes with a maintainer before starting work.
2. Create a separate branch for each change.
3. Follow the project's existing coding style.
4. Run the relevant tests before submitting a pull request.
5. Describe the changes and reference any related issues.

All changes require maintainer approval before merging.

## Issues and bug reports

Bug reports are welcome from anyone.
Permission to report an issue does not grant permission to contribute code.
